4. 已生成 sitemap.xml（16个页面）和 robots.txt

二、服务器配置（必须做，否则URL仍会显示index.html）
方法A：设置默认首页（推荐，最简单）
  虚拟主机/宝塔面板：在网站设置里把"默认文档"设为 index.html（排在第一位）
  Nginx：在 server 块里加 index index.html;
  Apache：在 .htaccess 里加 DirectoryIndex index.html

方法B：301重定向（更彻底，配合方法A使用）
  Nginx配置：
    if ($request_uri = /index.html) { return 301 /; }
  Apache .htaccess：
    RedirectMatch 301 ^/index.html$ /
