飞书400号码库 → 网站自动同步 配置指南
================================================================

【原理】
在飞书多维表格「400号码库」里增删号码 → GitHub Actions 每30分钟
自动运行同步脚本 → 生成新的 numbers.js → 提交到仓库 → GitHub Pages
自动重新部署 → 网站选号大厅显示最新号码。
全程免服务器，利用 GitHub Actions 免费额度。

【你需要做的4步配置】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第一步：创建飞书自建应用（获取 App ID 和 App Secret）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 打开飞书开放平台：https://open.feishu.cn/app
2. 点「创建企业自建应用」
3. 应用名称填：400号码库同步（随便填，自己能认出来就行）
4. 描述随便填，应用图标随便选，点「确定创建」
5. 创建后进入应用详情页，在「凭证与基础信息」里能看到：
   - App ID（类似 cli_a1b2c3d4e5f6）
   - App Secret（点「查看」获取，一串字符）
   把这两个值记下来，后面要用。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第二步：给应用开通权限并发布
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 在应用详情页左侧菜单点「权限管理」
2. 搜索并开通以下权限（点「开通」按钮）：
   - 查看多维表格数据（bitable:app:readonly）
   - 查看多维表格记录（base:record:retrieve）
   （如果搜不到上面的名字，搜 "bitable" 或 "多维表格"，
    把带"只读""查看"的权限都开通即可）
3. 左侧菜单点「版本管理与发布」
4. 点「创建版本」，版本号填 1.0.0，更新说明填"初始版本"
5. 点「申请发布」，如果是企业管理员会直接通过；
   如果需要审批，等管理员通过即可（自己的企业一般秒过）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第三步：把应用添加为「400号码库」表格的协作者
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 打开「400号码库」多维表格：
   https://my.feishu.cn/base/Vugfbq5D9aR7I5sBholcPFJjnEf
2. 右上角点「分享」按钮
3. 在「协作者」搜索框里输入你刚才创建的应用名称
   （比如"400号码库同步"），搜索结果里选这个应用
4. 权限设为「可阅读」（只读即可，不需要编辑）
5. 点「完成」或「确认」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第四步：在 GitHub 仓库配置 Secrets
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 打开你的 GitHub 仓库页面
2. 顶部点「Settings」（设置）
3. 左侧菜单找到「Secrets and variables」→ 点「Actions」
4. 点「New repository secret」按钮，依次添加两个：

   第一个：
   - Name: FEISHU_APP_ID
   - Secret: 你第一步记下的 App ID（如 cli_a1b2c3d4e5f6）
   - 点「Add secret」

   第二个：
   - Name: FEISHU_APP_SECRET
   - Secret: 你第一步记下的 App Secret
   - 点「Add secret」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【验证是否配置成功】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 打开 GitHub 仓库顶部「Actions」标签
2. 左侧能看到「同步400号码库」这个 workflow
3. 点右边「Run workflow」按钮 → 选 main 分支 → 点「Run workflow」
4. 等1-2分钟，刷新页面，看到这次运行显示绿色对勾就是成功了
5. 点进去看日志，应该显示"从飞书读取到 48 条号码记录"和"已生成 numbers.js"

如果显示红色叉号，点进去看错误信息：
- "获取tenant_access_token失败" → App ID/Secret 填错了，检查Secrets
- "读取记录失败" code 99991672 → 应用没加为表格协作者，回去做第三步
- 其他错误 → 把错误信息发我帮你看

【日常使用】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
加新号码：
  打开飞书「400号码库」表格 → 在最后一行下面直接输入新号码信息
  （号码/号段/等级/价格/寓意/状态）→ 等最多30分钟网站自动更新
  想立即更新：去 GitHub Actions 点「Run workflow」手动触发一次

下架号码：
  把该号码的「状态」字段改成「已售」，同步时会自动从网站移除
  （不删除记录，保留历史；想彻底删除也行）

修改号码价格/寓意：
  直接在飞书表格里改对应字段，同步后网站自动更新

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【表格字段说明】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
号码   ：完整号码，如 4000-888-6688（文本）
号段   ：4000/4001/4006/4007/4008/4009（单选）
等级   ：优选/精品/顶级/超级（单选）
价格   ：年预存参考价，单位元（数字）
寓意   ：号码寓意与说明（文本）
状态   ：在售/已售/预留（单选，默认在售，已售不显示在网站）
